# Omni Loco AI — Workspace Rules & Directives

## Automatic Git Push Protocol
- **Repository Remote**: `origin` (`https://github.com/blizza4d/omni_loco_ai.git`)
- **Branch**: `main`
- **Mandate**: Whenever any major updates, feature implementations, model upgrades, architectural refactors, bug fixes, or stability passes are completed and verified:
  1. Stage and commit all changes with structured, descriptive commit messages.
  2. Automatically push the commit(s) immediately to `origin main` (`https://github.com/blizza4d/omni_loco_ai.git`).
  3. Report the push status, remote SHA, and commit summary back to the user.
